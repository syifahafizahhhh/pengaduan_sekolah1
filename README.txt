CARA PASANG (Laragon)
1. Ekstrak folder "pengaduan-mimin" ke C:\laragon\www\
2. Start All di Laragon (Apache + MySQL).
3. Buka HeidiSQL/phpMyAdmin > Import database/mimin.sql (database MIMIN dibuat otomatis).
4. Buka http://localhost/pengaduan-mimin atau http://pengaduan-mimin.test
